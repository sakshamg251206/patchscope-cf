# Verified sources bound the resource claim

PatchScope-CF's defensible contribution is a compact, reproducible combination of controls. Existing work already covers graph-guided localization, frozen-commit retrieval, counterfactual evaluation, and masking. Its paper should explain precisely what its protocol isolates and attach every empirical conclusion to the project's own saved results. This source review supplies positioning and submission checks; it contains no project measurements.

## Prior work makes the narrow claim stronger

LocAgent establishes graph-guided code localization; Agent Retrieval Bench studies repository-context retrieval with frozen snapshots and wrong-repository controls. Bellam studies structural-tool placebos and gold-definition masking, while Caumartin and colleagues examine retrieval representations. These precedents rule out broad claims of inventing graph localization or counterfactual auditing. ([LocAgent](https://aclanthology.org/2025.acl-long.426/), [Agent Retrieval Bench](https://arxiv.org/html/2607.24882v1), [Bellam](https://arxiv.org/html/2610.33958v2), [Caumartin et al.](https://arxiv.org/html/2607.11046v1))

Safe wording is: **“PatchScope-CF packages a model-free audit combining directed-degree-preserving import-graph perturbations, identical lexical candidate pools, and a label-informed target-name query stress-test.”** This describes the resource, not a verified priority claim. The literature search did not establish that no equivalent protocol exists. Same-pool reranking also excludes discovery beyond that lexical pool; preserving degrees does not prove adequate null mixing, and query masking is diagnostic information removal.
